ENDPOINT - API REST Clinica Veterinaria (GA7-220501096-AA5-EV04)
Aprendiz: Manuel Passo
URL base: http://localhost:3000

AUTENTICACION
POST  http://localhost:3000/auth/registro                    Registrar usuario
POST  http://localhost:3000/auth/login                       Iniciar sesion
GET   http://localhost:3000/auth/usuarios                    Listar usuarios (sin claves)

MASCOTAS
GET   http://localhost:3000/mascotas/mostrar                 Listar todas
GET   http://localhost:3000/mascotas/{id}                    Consultar por id (404 si no existe)
GET   http://localhost:3000/mascotas/estado/{estado}         Listar por estado (Estable, Critico, Hospitalizado)
GET   http://localhost:3000/mascotas/propietario?correo=...  Listar por correo del propietario
POST  http://localhost:3000/mascotas/nuevo                   Crear
POST  http://localhost:3000/mascotas/modificar               Modificar
POST  http://localhost:3000/mascotas/{id}                    Eliminar (true/false)

Documentacion detallada: docs/API_DOCUMENTACION.md y docs/openapi.yaml
